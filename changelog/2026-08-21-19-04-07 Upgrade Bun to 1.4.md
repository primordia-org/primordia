# Upgrade Bun to 1.4

Primordia now pins Bun 1.4.0 in `mise.toml` and `package.json` so local development, worktree previews, and installer-managed production services use the newer runtime.

During validation, Bun 1.4 surfaced dependency-resolution issues around ESLint's legacy `minimatch` dependency and the existing `brace-expansion` security override. The lockfile now resolves `minimatch` through the modern 10.x line and keeps `brace-expansion` on the patched 5.0.9 range, preserving lint compatibility while avoiding the previous vulnerable brace expansion release.

Bun 1.4 validation also surfaced a React compiler lint violation on the Server Health page's imperative redirect. That redirect now uses `window.location.assign(...)`, and the reverse proxy no longer declares an unused runtime-root constant, leaving `bun run lint` clean under Bun 1.4.
