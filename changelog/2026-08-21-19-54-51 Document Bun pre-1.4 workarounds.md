# Document Bun pre-1.4 workarounds

Added `docs/bun-pre-1-4-workarounds.md`, an audit of compatibility code originally introduced for Bun 1.2/1.3-era runtime or Bun/Next.js interop bugs.

The document lists the raw-TCP WebSocket proxy tunnel, daemon keepalive timer, direct Next CLI execution through Bun, and generated Pi model registry boundary, with current code locations, changelog references, rationale, follow-up investigation prompts, and the child thread IDs created to retest each item on Bun 1.4.

The package.json investigation now records its Bun 1.4.0 result: the direct Next CLI-file invocation should stay because `bun run --bun next start` still leaves the listening production process as `node .../node_modules/.bin/next start`, while `bun --bun ./node_modules/next/dist/bin/next start` keeps it as `bun`.
