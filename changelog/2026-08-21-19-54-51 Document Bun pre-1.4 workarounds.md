# Document Bun pre-1.4 workarounds

Added `docs/bun-pre-1-4-workarounds.md`, an audit of compatibility code originally introduced for Bun 1.2/1.3-era runtime or Bun/Next.js interop bugs.

The document lists the raw-TCP WebSocket proxy tunnel, daemon keepalive timer, direct Next CLI execution through Bun, and generated Pi model registry boundary, with current code locations, changelog references, rationale, and follow-up investigation prompts for retesting each item on Bun 1.4. The WebSocket proxy item now records a Bun 1.4.0 investigation result: minimal `http.Server`/`http.request` probes show both historical HTTP upgrade bugs are fixed. The reverse proxy has been simplified accordingly: the external raw TCP classifier is gone, and WebSocket upgrades now use the normal `http.Server` `upgrade` event plus upstream `http.request()` while retaining preview/prod routing and lazy-start behavior.

It also notes that `bun run test:service-runtime` covers the installed-service launch path by verifying the supervisor, reverse proxy, and scheduled-jobs daemon start through `mise exec -C <primordia-root>` under the pinned Bun runtime.
